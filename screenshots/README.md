# Screenshots and Evidence

`vehicle_monitoring_terminal_preview.svg` is a visual preview rendered from actual sender/receiver console logs produced by the local test run. It is not a raw screenshot of a desktop terminal.

For formal evidence, capture your own Ubuntu terminal and Wireshark windows while running the project. Suggested filenames: `tcp_udp_communication.png`, `wireshark_tcp.png`, and `wireshark_udp.png`. Do not use screenshots from another repository as your project evidence.
